Iterations on C

Base stays C: wraith:engagement on line 1, a meta line that earns its place, red as the only accent. All three now style the footer: bordered quiet button for Clear Missing, red-text destructive button for Clear All, solid red Open. Row 1 is selected.

C1 · Git status bar

The meta line becomes a miniature git status using the gutter palette the sidebar already speaks: branch, ahead/behind, then added/modified/deleted counts in their own colors (+2 green, ~3 amber, -1 red). Date moves to the right edge of line 1 so line 2 is pure repo state. Remotes show the date until the SSH helper reports their status.

C2 · Adaptive height

Literal reading of "earns its place": a row gets a second line only when there is something to say. Local git repos show branch and state, deep files show their path, everything else collapses to a single line. Denser where the list is boring, informative where it is not.

C3 · State dot and hover actions

A small state dot leads each row: green for reachable or present, grey for an idle remote connection, red for unreachable or missing, replacing the old Unavailable chip. Hovering a row (shown on the cognel row) reveals inline actions: pin, reveal, remove, so management stops hiding in the context menu. Meta stays as in C2.
